# Security Policy

## Supported Versions

We release patches and bug fixes for the latest active version:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a potential security vulnerability within **prompt-trimmer**, please do NOT open a public issue.

Instead, please send an advisory email to the repository maintainers or use GitHub's private vulnerability reporting feature.

Please provide:
- A detailed description of the vulnerability.
- Steps to reproduce or a minimal proof of concept.
- Potential impact and affected components.

We will acknowledge receipt within 48 hours and work with you to release a timely patch.
